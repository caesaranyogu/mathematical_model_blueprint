# Mathematical Notation Reference

## Basic symbols

| Symbol | Meaning |
|---|---|
| \(x,y,z\) | variables |
| \(a,b,c\) | often constants/parameters |
| \(t\) | time |
| \(n\) | number of observations |
| \(i\) | index |
| \(\Delta\) | change/difference |
| \(\epsilon\) | error/noise |
| \(\theta\) | parameter vector |
| \(\hat{x}\) | estimate/prediction of x |

## Operations

\[
a+b
\]

Addition.

\[
a-b
\]

Subtraction.

\[
ab
\]

Multiplication.

\[
\frac{a}{b}
\]

Division.

\[
x^n
\]

Exponentiation.

\[
\sqrt{x}
\]

Square root.

\[
|x|
\]

Absolute value.

\[
a\bmod b
\]

Remainder.

## Relationships
\[
"="
\]

Equal.

\[
\neg with slash through
\]

Not equal.

\[
"<"
\]

Less than.

\[
">"
\]

Greater than.

\[
"<="
\]

Less than or equal to.

\[
">="
\]

Greater than or equal to.

\[
"squigly ="
\]

Approximately equal.

## Functions

\[
y=f(x)
\]

y is produced by function f using x.

\[
f(x_1,x_2,\ldots,x_n)
\]

A function can have many inputs.

## Summation

\[
\sum_{i=1}^{n}x_i
\]

Means:

\[
x_1+x_2+\cdots+x_n
\]

## Product

\[
\prod_{i=1}^{n}x_i
\]

Means multiply the indexed values.

## Calculus

\[
\frac{dy}{dx}
\]

Rate of change of y with respect to x.

\[
\int f(x)dx
\]

Accumulation/integration.

## Probability

\[
P(A)
\]

Probability of event A.

\[
P(A|B)
\]

Probability of A given B.

\[
E[X]
\]

Expected value.

\[
Var(X)
\]

Variance.

## Statistics

\[
\bar{x}
\]

Sample mean.

\[
\sigma
\]

Population standard deviation.

\[
s
\]

Sample standard deviation.

\[
Cov(X,Y)
\]

Covariance.

\[
Corr(X,Y)
\]

Correlation.

## Vectors

\[
\mathbf{x}
=
\begin{bmatrix}
x_1\\
x_2\\
\vdots\\
x_n
\end{bmatrix}
\]

A vector is an ordered collection of values.

## Matrices

\[
X=
\begin{bmatrix}
x_{11}&x_{12}\\
x_{21}&x_{22}
\end{bmatrix}
\]

A matrix is a rectangular array of values.

## Machine learning

\[
\hat y=f_\theta(x)
\]

Prediction generated by a model with parameters theta.

\[
\hat{\theta}=
\arg\min_\theta L(y,f_\theta(x))
\]

Choose parameters that minimize loss.
