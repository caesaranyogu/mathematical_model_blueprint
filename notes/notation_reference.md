# Mathematical Notation Reference

## Basic Symbols

| Symbol | Meaning |
|--------|---------|
| $x, y, z$ | Variables |
| $a, b, c$ | Often constants / parameters |
| $t$ | Time |
| $n$ | Number of observations |
| $i$ | Index |
| $\Delta$ | Change / difference |
| $\epsilon$ | Error / noise |
| $\theta$ | Parameter vector |
| $\hat{x}$ | Estimate / prediction of $x$ |

## Operations

$$a + b$$

Addition.

$$a - b$$

Subtraction.

$$a \cdot b$$

Multiplication.

$$\frac{a}{b}$$

Division.

$$x^n$$

Exponentiation.

$$\sqrt{x}$$

Square root.

$$|x|$$

Absolute value.

$$a \bmod b$$

Remainder.

## Relationships

$$=$$

Equal.

$$\neq$$

Not equal.

$$<$$

Less than.

$$>$$

Greater than.

$$\leq$$

Less than or equal to.

$$\geq$$

Greater than or equal to.

$$\approx$$

Approximately equal.

## Functions

$$y = f(x)$$

$y$ is produced by function $f$ using $x$.

$$f(x_1, x_2, \dots, x_n)$$

A function can have many inputs.

## Summation

$$\sum_{i=1}^{n} x_i$$

Means:

$$x_1 + x_2 + \cdots + x_n$$

## Product

$$\prod_{i=1}^{n} x_i$$

Means multiply the indexed values.

## Calculus

$$\frac{dy}{dx}$$

Rate of change of $y$ with respect to $x$.

$$\int f(x)\,dx$$

Accumulation / integration.

## Probability

$$P(A)$$

Probability of event $A$.

$$P(A \mid B)$$

Probability of $A$ given $B$.

$$E[X]$$

Expected value.

$$\text{Var}(X)$$

Variance.

## Statistics

$$\bar{x}$$

Sample mean.

$$\sigma$$

Population standard deviation.

$$s$$

Sample standard deviation.

$$\text{Cov}(X,Y)$$

Covariance.

$$\text{Corr}(X,Y)$$

Correlation.

## Vectors

$$\mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix}$$

A vector is an ordered collection of values.

## Matrices

$$
X = \begin{bmatrix}
x_{(1,1)} & x_{(1,2)} \\
x_{(2,1)} & x_{(2,2)}
\end{bmatrix}
$$

A matrix is a rectangular array of values.

## Machine Learning

$$\hat{y} = f_\theta(x)$$

Prediction generated by a model with parameters $\theta$.

$$\hat{\theta} = \arg\min_\theta L(y, f_\theta(x))$$

Choose parameters that minimize loss.
